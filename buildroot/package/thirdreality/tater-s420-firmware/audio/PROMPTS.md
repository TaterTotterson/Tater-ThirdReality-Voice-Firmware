# Tater S420 spoken prompts

- `setup_mode.wav`: “This Tater satellite is ready for setup. Connect to the Tater Setup Wi-Fi hotspot to continue.”
- `change_wifi.wav`: “Wi-Fi settings have been cleared. Connect to the Tater Setup Wi-Fi hotspot to continue.”
- `not_ready.wav`: “This Tater satellite is not ready. Connect to the Tater Setup Wi-Fi hotspot to finish setup.”
- `factory_reset.wav`: “Factory reset complete. Connect to the Tater Setup Wi-Fi hotspot to set up this Tater satellite.”

The clips are 48 kHz, stereo, 16-bit PCM WAV files for compatibility with the
vendor PulseAudio configuration. No Home Assistant onboarding prompt is
installed in the Tater image.
